# Sample Test Flow

1. Open Dashboard.
2. Select **Add Student**.
3. Enter Roll Number `259`, Student Name `Firdaus`, Marks / CGPA `9.5`.
4. Select **Add Student**.
5. The dashboard count becomes 1 and the record appears under Students.
6. Search `259` from Search → Roll Number.
7. Search `Firdaus` from Search → Student Name.
8. Edit the record and change the score.
9. Delete the record and confirm.
10. Add multiple students and open Analysis to see highest, lowest, average and score distribution.
11. Refresh the browser and confirm that saved records remain available on the same browser.
